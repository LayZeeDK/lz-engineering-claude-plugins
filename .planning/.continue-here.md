## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Verify block that passes on a no-op | A chain that exits 0 with the task undone | blocking | Run it verbatim against an unmodified tree and record the OBSERVED exit code |
| Coverage hole in a verify chain | Every other leg present, the one that matters absent | blocking | Enumerate the task's own steps and map each to a leg; BLOCKER-1 is exactly this |
| Blast radius asserted, not measured | A "MEASURED -- do not exceed it" heading over a wrong site list | blocking | Re-run the count; BLOCKER-2 named 9 sites for a phrase occurring on 5 lines |
| Fail-open guard on an absent subject | `git grep` writes its fatal to stderr, so `wc -l` is 0 and the leg passes | blocking | Assert a non-empty file list was actually scanned before asserting the content |
| Fix breeds the same defect class | Four rounds, four self-falsifying claims, each arriving in the previous repair | blocking | Derive the claim from the data with a guard rather than asserting it in prose |
| Needle outlives its subject | A guard keeps passing after the prose it protects is reworded | blocking | Scope by a stable key and assert against a named slice |
| Inferring behavior from structure | "It is linked, therefore it loads" | advisory | Trace the actual routing path before claiming it |
