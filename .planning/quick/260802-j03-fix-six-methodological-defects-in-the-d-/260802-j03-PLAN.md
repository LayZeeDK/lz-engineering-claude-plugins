Authored 2026-08-02, BEFORE any pilot run. This section is the pre-registration of record. Task 2

The prior round's discriminator (`changed_production_files`) was correct on **18 of 18** runs --
non-empty on every `a1`, empty on every `a2`, in all three arms. That is a CEILING, not a tie. k=5
buys observability ONLY IF the D-03 cut moves it. If it does not, the fixed round reproduces the null
at ~1.7x the prior cost and every other fix here will have improved a measurement that still cannot
measure anything.

```
  --mode apply --cwd D:/.lz-red-throwaway/srvx-d12 \
  --arm invoke_skill --prompt a1 --runs 3
```

**MEASURED budget correction.** CONTEXT and RESEARCH both cite ~$0.91/run. That is the ALL-CELL mean
over the 18 prior runs and it UNDERSTATES this pilot by ~37%, because the pilot is three `a1` runs and
`a1` is the expensive prompt. Measured 2026-08-02 from the prior round's `meta.json` files:

### The rule

Read `changed_production_files` on the pilot's `red-grade.json` files. Let **N** = the number of
GRADEABLE pilot runs whose `changed_production_files` is NON-EMPTY, out of 3.

| N | Verdict | Action |
|---|---|---|
| **3** | **CEILING HELD.** The rewritten `a1` is resolved correctly by the baseline every time, exactly as the un-rewritten one was. | **STOP. Do NOT buy the round.** Report the ceiling as the finding, keep `FUT-TAXONOMY-SHARED` OPEN with status NOT-YET-TESTED, and record that D-03 did not move the baseline. |
| **0, 1 or 2** | **CEILING MOVED.** At least one baseline run failed to resolve the prompt to the production side -- the first such observation in 21 prior baseline+arm runs on this discriminator. | **Buy the round:** k=5, 3 arms x 2 prompts = 30 runs, ~$27. |

The threshold is deliberately permissive. The pilot is a GO/NO-GO on OBSERVABILITY, not a hypothesis
test: the round is powered to detect a 10/10-vs-6/10 split, and a baseline base rate below 100% is the
precondition for detecting anything at all.

### Void runs (fail closed on EVIDENCE, not on spend)

A pilot run that produces no `red-grade.json` -- empty diff, `assertReadableDiff` throw, grade-red
throw -- is **VOID**, not evidence. It is neither an N-hit nor an N-miss.

- Re-run that index until **3 GRADEABLE** runs exist. The gate is read on 3 grades, never on 2.
- Cap: at most **2** void re-runs (~$2.47 additional). If 3 gradeable runs cannot be obtained within 5
  attempts, **STOP** and report the stall rate itself as the finding.

### What is reported but is NOT the gate

Verdict distribution (`genuinely_red` / `blunt_red` / `compile_error` / `unattributable` / ...) is
recorded alongside and read second. The discriminator is `changed_production_files`, for the reason
the cell was built that way: it is immune to naming.
