<objective>
Build the genuinely-new logic of the phase: the D-06 RED correctness gate. `grade-red.mjs` takes a
captured run (diff.patch + meta.json), applies the produced test to a fresh throwaway worktree at
applyBase, differential-typechecks it, runs the target's own test runner, and classifies whether the
test is genuinely red for the right reason -- or a compile error, a collection error, zero tests, a
false green, or a drove-to-green. It writes `red-grade.json` per run and proves itself offline on
`fixtures/` test-pairs with zero spend.

Purpose: correctness is the ONE hard gate (D-06); everything else is a reported lift dimension. It
must be mechanical (run the test, not word-match) so no house-vocabulary proxy can inflate it
(Phase-20 lesson). The classifier is ~1 screen; the care is in the differential tsc scope (Pitfall
3), running the TARGET's runner not the workspace's (Pitfall 4), splitting drove_to_green from
false_green (Pitfall 9), and failing closed on garbled input.

Output: grade-red.mjs + its --selfcheck + the five fixture test-pairs. No metered run.

## Locked decisions honored
- **D-06:** (hard GATE) correctness = tsc --strict clean (differential -- NEW errors from the test only) AND genuinely RED for the right reason (an assertion failure on current code, not a compile/setup error, not a false green). A run that is not correctness-clean does not count as a pass. The classifier is the mechanical decision procedure for this.
- **D-12:** build + zero-spend selfcheck freely; the metered run is gated. grade-red --selfcheck runs offline on fixtures (never claude); fixtures are SELFCHECK-ONLY and never eval targets; NO dependency added to plugins/lz-tdd.

## Notes for the executor
- grade-red is a POST-RUN pass over captured artifacts (mirrors Phase 13's `grading/*` reading captured diffs); it does NOT drive claude and does NOT modify run-e2e.mjs.
- The classifier logic is shared between the real gate and --selfcheck; only the runner command + cwd differ (target toolchain vs the fixture's local runner). Parameterize accordingly.
- The workspace already pins typescript@6.0.3 + vitest@4.1.10 (dev deps) -- use them ONLY for the fixtures selfcheck. Real runs shell into the TARGET repo's tsc + runner (recorded in red-grade.json for drift detection).
</objective>
