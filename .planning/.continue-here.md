## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Author-graded criteria | "This guard is closed" asserted in prose rather than demonstrated. Three rounds, three defects: a comment claiming a stale figure "understated" a budget when it OVERSTATED it, a claim that a 1508-char edit was "over-cap" when 1508 is UNDER the 1536 cap, and a double-space bug inside a fold repair that inflated every measured length. | blocking | Run the evasion suite. An item is closed when its line flips EVADED -> CAUGHT, not when you believe it. |
| Unverified mutation | A `sed`/`replace` anchor spanning a hard-wrapped line silently does not match; the gate runs against unmodified files and reports GREEN. | blocking | Verify the mutation is present in the file before running the gate; a non-matching anchor FAILS as BAD TEST. |
| Pipeline exit code | `rg pattern file \| head` reports **head's** status, not rg's. This produced a reported "exit 0" for a command that exits 1. | advisory | Measure exit codes without pipes. 0 = hits, 1 = genuine absence, 2 = the command FAILED and tells you nothing. |
| Case-sensitive `git grep` | A documentation check reported text missing when it was present, because the header spells it `LITERAL BLOCKLIST` and the check searched lowercase. | advisory | Use `-i` for prose/documentation checks, and pair every absence claim with a positive control on the same path. |
| `rg` cannot read Git Bash `/tmp` | `rg` is a Windows binary; a `/tmp/...` path created by Git Bash resolves as `C:\tmp` and it exits **2** -- indistinguishable from "no matches" if you only read output. | advisory | Redirect captures into the session scratchpad path, not `/tmp`. |
| Closing a blind spot region-by-region | The same defect shape was found FOUR times, each one level out from the last: prose above the first `## `, then the lead-in before branch `a.`, then between the heading and item `1.`, then later numbered steps. | advisory | Prefer a check quantified over a WHOLE region to another sub-region check. That is why the coarse whole-section scan exists. |
