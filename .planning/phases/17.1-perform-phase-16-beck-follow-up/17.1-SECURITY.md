## Observations (non-blocking, no status change)

1. **`check-hygiene.mjs` scope excludes `.planning/`.** This phase modified one committed
   `.planning/` file (`16-CONTEXT.md`), which therefore sits outside the standing mechanized
   email and ASCII scan. The auditor verified it clean with an independently authored
   allowlist-inversion scan, but there is no standing regression guard for committed
   `.planning/` content. The declared mitigation does what it declares -- this is a scope
   note, not a gap.
2. **One benign regex hit, recorded so it is not re-investigated.** The independent
   allowlist-inversion scan over all phase-modified files, phase planning artifacts and all
   five phase commit messages returned exactly one email-shaped match, at
   `17.1-VERIFICATION.md:86`. Classified without echoing it: the local part is `lz-tdd` and
   the domain part ends in `.md` -- a version-scoped Markdown filename of the
   `lz-tdd@<version>-REQUIREMENTS.md` shape, not an address. Zero real non-allowlisted
   emails. Expect the same benign hit if the scan is repeated.
3. **The oracle-reviewer gate is attested, not replayable.** Its per-surface verdicts survive
   only as orchestrator prose in SUMMARY.md; no reviewer transcript is committed. That is the
   correct trade-off -- a committed transcript would risk carrying essay prose across the
   DST-04 clean-room boundary -- and the verdicts are corroborated three ways: the
   differentiated finalize diff, the VALIDATION Gap 3 / Gap 4 cross-read, and the standing
   machine check. Recorded so the limitation is stated rather than silently assumed away.
