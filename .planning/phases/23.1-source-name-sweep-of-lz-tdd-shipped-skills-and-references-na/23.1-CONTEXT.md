<domain>
## Phase Boundary

The shipped plugin tree `plugins/lz-tdd/` (skills, references, READMEs) names no people, conferences, talks, books,
articles, podcasts or similar, and cites no chapters; named patterns and techniques stay. Credit moves to one shipped
file, `plugins/lz-tdd/ATTRIBUTION.md`. A TypeScript check, modelled on lz-oop's `tools/citations.ts`, fails the build
when a title, a chapter citation or a stand-in appears outside ATTRIBUTION.md. Every repo checker that mirrors the
swept text moves with it in the same commit. Before and after are measured on the Phase 22.1 harness: Phase 23's after
run is the names arm, one new no-names arm is run (about 51 USD, srvx included), and the run waits for Lars's yes at
run time.

Not in this phase: the TDDux rename (Phase 23.2); workspace and planning files outside `plugins/lz-tdd/` (they are not
shipped); new skills or behaviour changes.

</domain>

<decisions>
## Implementation Decisions

### Locked by Lars (verbatim in ROADMAP Phase 23.1)
- **D-01:** No names of people, conferences, talks, books, articles, podcasts or similar in shipped skills and
  references (Lars 2026-11-24, "Similar to lz-oop, ...").
- **D-02:** Person names go too, "Remove all agreed names", except where a person's name is the usual name of a
  concept (Lars 2026-11-24).
- **D-03:** Measured, two arms on the 22.1 harness; per-group arms only if no-names does worse (Lars 2026-11-24).
- **D-04:** Budget: one new arm with srvx at about 51 USD; Phase 23's after run is the names arm when the shipped text
  is unchanged between it and this phase's start, which the plan checks before spending (Lars 2026-11-25).
- **D-05:** When the result record exists, send its path to the lz-oop session (OOdour, the renamed lz-oop session).

### What counts as a concept name (D-02 exception)
- **D-06 [auto]:** A name stays only when it is the standard name of the thing itself, as a reader would search for
  it: none of the current hits qualify on inspection except where planning finds a standard term that cannot be said
  another way. Possessive and attribution forms always go ("Beck's ...", "Fowler's catalog", "per Kerievsky",
  "Martin's TPP"): the concept keeps its own name (Test Desiderata, Transformation Priority Premise, seam, Tidy First as
  a technique name only if planning shows it is the technique's usual name and not the book title).
  Trade-off: a strict rule (strip every person token) vs. a concept list (keep a short allowlist). Recommended: an
  explicit allowlist in the check, empty by default, each entry with a one-line reason, so every kept name is a
  visible decision. "GoF" is a group label for authors, so it goes; "design pattern" names stay.
  — **Reversibility:** reversible — an allowlist entry can be added later.

### Names in paths
- **D-07 [auto]:** File and folder names that carry a source name are renamed to neutral names in this phase:
  `beck-tidy-first.md`, `fowler-catalog/`, `kerievsky-catalog/`, `gof-catalog/` and any other path the scan finds.
  Paths appear in links and in the skill text, so a kept path is a kept mention. Use `git mv`; every link, checker
  selector and eval case path that names them moves in the same commit.
  Trade-off: keep paths (less churn, but names stay visible in every link) vs. rename (one large mechanical commit).
  Recommended: rename, because D-01 covers links.
  — **Reversibility:** costly — links, checkers and eval cases name the paths; undoing means a second sweep.

### Source tags and chapter citations in leaves
- **D-08 [auto]:** Per-leaf `Source:` lines and chapter citations (`Ch.N`, 58 hits today) leave the shipped text. The
  mapping from leaf to source lives in ATTRIBUTION.md at work level (book, talk, article), not per chapter, in the
  lz-oop form. Checkers that require a per-leaf Source tag (check-catalog, check-kerievsky, check-smells, check-gof,
  check-functional, check-extra-patterns, check-backing, check-principles, check-red-references) are rewritten to
  assert the new shape instead, in the same commit as the text they mirror.
  — **Reversibility:** costly — the checkers' contracts change with the text.
- **D-09 [auto]:** The Kerievsky "Direction" field (To / To-Towards / Away / n-a) stays as a field; only its source
  label is renamed to a neutral heading.

### ATTRIBUTION.md
- **D-10 [auto]:** Mirror lz-oop's `plugins/oodour/ATTRIBUTION.md`: an opening paragraph saying the plugin is
  original writing and quotes and cites none of the works in its working text, then sections Books, Talks and
  articles, each entry author, italic title, edition and year. Include the Fowler sources here (folded todo item C9,
  per Phase 23 D-16). ATTRIBUTION.md is the only shipped file the check exempts.

### The check
- **D-11 [auto]:** A new `tools/evals/check-citations.ts` (or the workspace that owns the shipped-text checks, chosen
  in planning) with a `.test.ts`, ported from lz-oop `tools/citations.ts`: chapter citations, titles parsed from
  ATTRIBUTION.md, author names parsed from ATTRIBUTION.md, and stand-ins ("the book", "the talk", "the article"),
  across every shipped `.md` except ATTRIBUTION.md. It runs in `npm run check`. Script bar: erasable TS, tests on
  Node 22 and 24, `tsc` clean, Stryker with the pinned lz-node-test runner, review.
  Detect by parsing ATTRIBUTION.md, never by hardcoding a name list in the check (one source of truth).
- **D-12 [auto]:** The check is written RED first against today's tree (it must report the current hits), then the
  sweep turns it GREEN.

### Measurement
- **D-13 [auto]:** Arms and cells exactly as Phase 23's after run, so the two compare row by row. The plan first
  checks that `plugins/lz-tdd` at Phase 23's after-run ref equals this phase's start; if it differs, it prices a fresh
  names arm and stops for Lars. The paid run is the last plan and waits for Lars's yes and a USD cap.
