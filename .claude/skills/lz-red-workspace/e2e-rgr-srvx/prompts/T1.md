Frameworks built on srvx want to throw their own error when a request body is too large, instead of matching on `ERR_BODY_TOO_LARGE`. Add a `createError(max)` option to `limitRequestBody` and `limitBodyStream` in src/body-limit.ts, passed as a third argument (`{ createError }`). Whatever it returns should be what gets thrown everywhere the over-limit error is thrown today. Without the option, nothing changes.

Do it test-first with the lz-tdd plugin. The tests live in test/body-limit.test.ts; run them with `npx vitest run test/body-limit.test.ts`.
