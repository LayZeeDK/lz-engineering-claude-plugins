<objective>
Build the reporting + offline-proof half of the instrument: `tabulate-mechanical-red.mjs` (mechanical
lift dims + Pass@k/Pass^k on the correctness gate), `selfcheck-red.mjs` (the zero-spend crux battery
that proves the whole harness before any spend), and the `EVAL-RESULTS.md` scaffold (blank tables +
reserved unbiased-reviewer slot + substance-only headline). Judge/oracle-reviewer are WIRED, not run.

Purpose: mechanical dims come free from the stream-json meta; correctness is the pass gate; Pass@k
tells sampling reliability. The selfcheck is the build-then-halt boundary (D-12) -- it proves
composition, prompt-parity, worktree teardown, transcript parse, the classifier, and the lz-refactor
regression, all offline. The results scaffold bakes in the Phase-20 lessons: substance-only headline
(D-08) and a mandatory unbiased reviewer (D-10) that caught the ~3x vocabulary inflation.

Output: tabulate-mechanical-red.mjs + --selfcheck, selfcheck-red.mjs, EVAL-RESULTS.md scaffold, and
the tabulate fixture samples. No metered run.

## Locked decisions honored
- **D-07:** Report (not pass/fail) the lift dims -- wall-clock, tool usage, token usage (mechanical from stream-json meta), output quality, book/source authenticity (oracle-reviewer, DST-04), idioms, house style, TDD RED practices. tabulate handles the mechanical ones; the graded ones are wired to blind judge + oracle-reviewer.
- **D-08:** SUBSTANCE-ONLY is the headline wherever any vocabulary proxy is used; any full-run vocabulary number is labeled context only. Bake this into the EVAL-RESULTS structure; the correctness gate is mechanical (no vocabulary proxy) and stays the pass criterion.
- **D-09:** Mechanical dims via tabulate-mechanical-red.mjs; graded dims via blind LLM judge (<= 2 dims per judge, blinded to the arm by feeding only the test code + behavior spec); book authenticity via oracle-reviewer against .oracle/ (clean-room). Pass@k + Pass^k per target + overall.
- **D-10:** Reserve a >= 1 from-scratch UNBIASED reviewer slot in EVAL-RESULTS.md (neutral brief, no prior findings) -- mandatory; it is the Phase-20 safeguard that caught the vocabulary inflation.
- **D-11:** Reuse merge-judge.mjs (selfcheck-GREEN) + oracle-reviewer verbatim; the selfcheck imports the parameterized run-e2e.mjs + grade-red.mjs rather than reimplementing them.
- **D-12:** selfcheck-red.mjs is zero-spend (never calls claude); the metered run is gated to 21-04. No dependency added to plugins/lz-tdd.
</objective>
