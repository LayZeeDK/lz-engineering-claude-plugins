On AWS Lambda (payload 2.0), when an event has both `headers.cookie` and a `cookies[]` array, the handler sees every cookie twice. `cookies[]` should win when it is present and not empty; otherwise keep `headers.cookie`. Going the other way, `requestToAwsEvent` should put each cookie in its own `cookies[]` entry, not the whole header as one entry.

Fix it test-first with the lz-tdd plugin. The tests live in test/aws.test.ts; run them with `npx vitest run test/aws.test.ts`.
