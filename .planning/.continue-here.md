  `gsd-verifier` returned `passed` at 12/12 must-haves while an UNPRIMED content reviewer returned
  NEEDS WORK on the SAME artifacts at the SAME HEAD. Both were right. The verifier checked entries
  EXIST; the reviewer checked their content is TRUE. Run both, and run the content review unprimed.
- [ ] **PROVE A GUARD CAN FAIL BEFORE TRUSTING IT.** Chain with `&&`, never `;`, and assert every leg.
  Every guard touched this session has a recorded RED-then-GREEN pair.
- [ ] **TWO PROOF KINDS, NEVER BOTH OF ONE GUARD.** RED-at-baseline with a `file:line`, or
  invariant-GREEN with a fixture set. For a presence-required guard the RED evidence is "phrase absent
  from `<file>`, measured count 0" -- demanding a `file:line` there is unsatisfiable.
- [ ] **NEVER READ `.oracle/` CONTENT, INCLUDING INDEX FILES.** Copyright firewall. `ls`/`find` for
  existence only. Only the `oracle` agent reads it.
- [ ] **MEASURE; DO NOT RELAY, AND DO NOT INFER FROM STRUCTURE.** A link existing is not evidence a file
  loads. A regex tested in isolation is not evidence a guard fires -- read the code that RUNS it.
- [ ] **A REASONED CLEARANCE OF A SET IS NOT EVIDENCE. ENUMERATE IT.** A planner cleared the remaining
  `$(... | wc -l)` legs by argument; forcing an actual enumeration found THREE fail-opens, none of them
  in the set the argument had considered -- and the argument's verdict happened to be right for a
  property it had never identified. A dismissal can be correct in its verdict and worthless as evidence.
- [ ] **"REPLACE X WITH Y" NEEDS TWO LEGS, ONE PER DIRECTION.** A leg asserting Y is present is NOT
  coverage: an executor can satisfy an addition by appending while leaving X intact. Assert X is GONE
  and Y is PRESENT. This was missed twice this session, once in a leg written to close a related gap.
- [ ] **A TWO-ARM FAIL-OPEN NEEDS BOTH ARMS CLOSED.** `git diff <tag> -- <path> | wc -l` launders the
  upstream exit status. A `rev-parse` anchor closes the TAG arm and leaves the PATH arm open -- a typo'd
  path still yields 0 and PASSES. Anchor the tag AND assert the paths exist (`[ -d ]` / `[ -f ]`).
- [ ] **NEVER TRUST A ZERO WITHOUT A POSITIVE CONTROL.** Three distinct mechanisms produced the same
  confident zero this session: ripgrep's HIDDEN-directory skip over dot-prefixed `.claude/`, line-oriented
  matching against a phrase that wraps, and a phrase wrapping across a `//` comment prefix. **The hidden
  skip is NOT gitignore** -- `git check-ignore` reports those files NOT ignored, and `--no-ignore` alone
  does NOT fix it. Only `--hidden` does (`-uu` works because it implies it). MEASURED.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Fix breeds the same defect class | Every repair round in this task introduced something, and it was always caught by the agent RECEIVING the fix, never the one proposing it | blocking | Keep propose and apply adversarially split; re-read your own diff against this table before returning |
| Guard replaced with inverted polarity | `git diff --quiet` (fail-CLOSED on a bad revision) was replaced by a `wc -l` form (fail-OPEN), and the argument for it was written into a comment | blocking | When replacing a guard, state which DIRECTION the old one failed in before claiming the new one is better |
| Partial repair of a two-arm fail-open | An anchor closed the tag arm and left the path arm open, on the sole mitigation for the one threat rated critical | blocking | Enumerate every arm; anchor each; prove with a bogus input per arm |
| Leg enforces addition but not removal | A "replace X with Y" requirement legged only Y's presence, so appending satisfied it while X survived | blocking | Two legs, opposite directions, per replace-requirement |
| Fail-open by comparison DIRECTION | `\|\| echo 0` and pipe-into-counter collapse a genuine no-match AND a path failure to `0`. Safe for `-ge N`; PASSES for `-eq 0` / `-le N` | blocking | Classify every leg by direction; anchor every absence/ceiling assertion with a counted positive control on the SAME subject EARLIER in the SAME chain |
| File-wide count where the construct lives elsewhere too | `TWO_IG_GUARDS` measured 0 in the target slice but 4 file-wide, so a file-wide leg would have been the class it closed | blocking | Region-scope by bracketing between two single-occurrence keys; anti-vacuity-assert the slice is non-empty |

| Claim outlives the guard it describes | A removed guard left its claim in the GREEN SUMMARY; a rescoped gate kept a comment saying the archive was in scope | blocking | Grep the guard's label AND its prose when removing or rescoping it |
