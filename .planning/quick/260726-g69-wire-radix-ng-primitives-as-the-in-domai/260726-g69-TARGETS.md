## 6. GRADER-ARTIFACT HAZARD -- substring assertions are UNSAFE here

Reproduced deliberately, same fixture, `provideRadixNG({ locale: 'de' })`, actual text `January 1980`:

```ts
expect(heading.textContent).toContain('Januar');            // PASSES  <-- FALSE GREEN
expect(heading.textContent?.trim()).toBe('Januar 1980');    // FAILS   <-- correct
```

`'January'.includes('Januar') === true`. Vitest's own diff renders it as `Received: "Januar[y] 1980"`.

The SAME class applies to CAND-2: `data-focus` is a strict PREFIX of `data-focused`, so an
attribute-name substring or `startsWith` check false-greens there too.

**Grading rule to encode: exact `toBe` on trimmed text; never `toContain`/`toMatch`/`startsWith` on
these needles.** Any canary fixture authored for these targets must honour it.
