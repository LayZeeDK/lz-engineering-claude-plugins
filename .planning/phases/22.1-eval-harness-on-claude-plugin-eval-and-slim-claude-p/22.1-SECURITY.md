## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Harness -> Claude Code CLI | `eval.ts` spawns `claude plugin eval` and slim `claude -p` with argument arrays | prompts, plugin files, allow lists; the CLI's JSON and traces come back untrusted |
| Harness -> third-party template code | `templates.ts` installs and builds the kata and srvx templates under `D:/tmp` | pinned commits and lockfiles in; build and test code runs with the user's access (O-2) |
| Agent under test -> run folder | a session with Write or Edit grants works in a staged plugin copy or a slim run copy | file writes limited by the CLI's sandbox and by copies that hold no links |
| Run output -> public repository | `aggregate` renders RESULTS.md from raw results | names and numbers only; raw run folders are git-ignored |
