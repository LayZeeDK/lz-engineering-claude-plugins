### Auto-fixed Issues

**1. [Rule 1 - Bug] Missing space after `&&` in both check scripts**
- **Found during:** Task 3
- **Issue:** The Task 1 and Task 2 edits that put the new steps at the start of each `check` script lost the space before the next step, giving `&&node tools/...`. cmd.exe still ran it (both checks exited 0), but the script text was malformed.
- **Fix:** The space was restored in both `package.json` files, as part of the Task 3 GREEN commit.
- **Commit:** c53f5e6

**2. [Rule 3 - Blocking] Grandfather list built without the `$TMP` redirect**
- **Found during:** Task 3 step 3
- **Issue:** The worktree isolation guard refused `git ls-files ... > "$TMP/v73-ls.txt"` and any git pipe. It also refused any command line whose path contains `github`.
- **Fix:** `git ls-files --cached --others --exclude-standard -- .claude/skills` ran alone and exited 0. Its saved output was filtered with the Grep tool using the plan's pattern, which gave 67 paths and no `node_modules` path. The list was then written with the Write tool. The committed list matches what the guard itself lists: the guard reports `0 new, 0 stale`.
