<objective>
Stage the three placement variants and prove the whole arm setup offline. This plan authors the shared
routing table as a workspace SOURCE artifact, builds the variant B and C trees into the gitignored
build-output directory with fail-closed transforms, and writes the sibling selfcheck that proves the
three arms compose distinctly off one byte-identical prompt with byte-identical descriptions.

Purpose: the A/B is only meaningful if the three trees differ in EXACTLY the declared way and in nothing
else. Two failure modes are specifically fatal and both are silent: a transform whose anchor was
reworded no-ops and produces a healthy-looking tree whose lever is absent, and a description that drifts
by one byte turns a placement measurement into a triggering measurement. Both get an explicit assertion.

Output: `variants/rgr-routing.md`, `variants/build-variants.mjs`, `selfcheck-routing.mjs`, and two
generated trees under the gitignored build-output directory. Nothing ships; nothing metered runs. The
RUN-GATE, the writeup scaffold and the double HALT are 22-07's.

## Locked decisions honored
- **D-08:** The three variants are staged so they can be measured: A inline only (the tracked tree), B the shared table plus a short inline classify-first rationale, C the shared table replacing the three per-skill narrative sections with `SKILL.md` keeping only its short branch list and a link-out. The precedent for the shared form is the plugin-wide reference this phase already repaired.
- **D-09:** Author all three variants, measure, ship only the winner. This plan finishes the authoring half; the measuring half is owner-gated.
- **D-10:** Variant C is the pre-registered null tiebreak, and its disclosed risk is real: it moves the classify-first rationale behind a lazy read, and classify-first is one of only two scenarios where a prior behavior eval measured a genuine edge. The builder must therefore keep C's inline branch list intact, and the writeup must not read a tie as C being free.
- **D-11:** Three trees toggled via the driver's read-only `--plugin-dir` consts, with byte-identical descriptions across trees as the precondition. Assert it as a hash comparison, per skill per tree.
- **D-24:** Variant A is the TRACKED tree. It needs no generated copy, it is the composition anchor the existing selfcheck already asserts, and it adds no shipped file -- so the shared table's source lives in the workspace, not in the shipped tree.

build-output directory, whose paths are the hardcoded twins of the driver's read-only consts.
No shipped file is added or changed by this plan.
