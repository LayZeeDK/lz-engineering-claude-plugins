## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Verify block that passes on a no-op | A chain that exits 0 with the task undone | blocking | Run it verbatim against an unmodified tree and record the OBSERVED exit code |
| Coverage hole in a verify chain | Every other leg present, the one that matters absent | blocking | Enumerate the task's own steps and map each to a leg; the plan now carries a `<step_leg_map>` doing this for all 47 steps |
| Blast radius asserted, not measured | A "MEASURED -- do not exceed it" heading over a wrong site list | blocking | Re-run the count; one round named 9 sites for a phrase occurring on 5 lines |
| Fail-open guard on an absent subject | `rg`/`git grep` write their fatal to stderr, so `wc -l` is 0 and the leg passes | blocking | Assert a counted positive anchor on the SAME subject earlier in the SAME chain, before asserting content |
| Fail-open by comparison DIRECTION | `\|\| echo 0` collapses a genuine no-match AND an exit-2 path failure to `0`. Fine for `-ge N`; PASSES for `-eq 0` / `-le N` | blocking | Classify every guarded leg by direction; anchor every absence/ceiling assertion |
| Fix breeds the same defect class | Six rounds, six self-falsifying claims, each arriving inside the previous repair | blocking | Derive the claim from the data with a guard rather than asserting it in prose; re-read your own diff against this table before returning |
| Needle outlives its subject | A guard keeps passing after the prose it protects is reworded | blocking | Scope by a stable key and assert against a named slice; bracket BETWEEN two single-occurrence keys |
| Label claims more than its needle enforces | `[lc9] mockist attributed to Fowler` enforced only a file-wide `Fowler's label` | blocking | For each leg, name what it PROVES vs what the prose CLAIMS; a leg passing for an adjacent reason is worse than no leg because it reads as coverage |
| Inferring behavior from structure | "It is linked, therefore it loads"; a newline-bearing needle against a per-line matcher | blocking | Read the code that RUNS the check (`:549` splits on `\r?\n`, `:552` tests per line), then drive the real instrument |
| Constant on both sides of an assertion | A roster entry referencing the same constant the emitter pushes | blocking | String literals in roster arrays; a rename must break something |
| Guard deleted, its output claim left behind | GREEN SUMMARY still advertised a removed guard | blocking | Grep the guard's label AND its summary prose when removing it |
| LSP diagnostics dismissed wholesale | 2 of 3 "declared but never read" were stale, but 1 was a genuine dead helper | advisory | Verify each claim against the source rather than trusting or dismissing the feed as a block |
