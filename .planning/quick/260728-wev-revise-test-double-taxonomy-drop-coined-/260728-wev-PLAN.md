## Already resolved, wording only: what a tier does and does not promise

NOT A DECISION AND NOT A GATE. NOTHING IN THIS PLAN BLOCKS ON AN OWNER CHOICE -- the one blocking
decision it used to carry has been withdrawn, and this block is only here to fix the SITE so the
executor does not scatter the qualifiers.

SITE: the closing tier-rule block at taxonomy lines 307-310. Extend that block -- do not create a
new section, and do not spread the qualifiers across section 6, because the point is that the tier
VOCABULARY over-promises, which is a property of the tier system and belongs with the tier rule.

The extended block states three qualifiers on top of the existing per-row rule:

1. By CLAIM TYPE. Prose claims from print hold up. TABLE and other STRUCTURAL claims, from any
   medium, are unreliable and require direct verification. The cross-reference table was misread
   twice, once by a reader explicitly asserting two independent structural signals and denying the
   precise hazard it had been warned about. Two markup traps caused it: a spanning super-header
   carrying one cell more than the table declares, and header rows marked up as data cells rather
   than header cells.
2. By SOURCE MEDIUM. Automatic-transcript sources are weaker, and the corollary a reader needs is
   that for such sources ABSENCE claims are the weak case -- a single mistranscription hides a hit.
   Reliability is per source and depends on transcription quality, not on the medium alone, so the
   rule is to NAME THE SOURCE rather than to discount all video. Currently weaker: the Metz talks,
   the Beck talks, the Cooper talks. EXEMPT and trustworthy: both Bernhardt sets.
3. By SOURCE VERSION. A tier records that a source was verified. It does not record WHICH VERSION
   was verified. When a source is later re-acquired or re-transcribed, every finding drawn from the
   earlier version silently inherits a tier it no longer earns. Any row whose source has been
   re-acquired since the row was written requires re-verification before its tier can be trusted.

NAME THE BERNHARDT ROW AS THE CONCRETE CASE for qualifier 3, with BOTH of its facts: its
verification is stale because the transcript it was verified against has been replaced, AND its
source citation was ambiguous between two materially different deliveries.

DO NOT downgrade every row. The failure was not random and a blanket caveat would discount roughly
thirty sound rows because of one bad cell. The honest fix is to name the limit, not to lower
everything.
