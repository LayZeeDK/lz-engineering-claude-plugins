# BLOCKING CONSTRAINTS -- Read Before Anything Else

> These are not suggestions. Every one below was discovered through an actual failure in the
> 2026-07-27/28 session, not predicted. Acknowledge each explicitly before proceeding.

- [ ] CONSTRAINT: **Never edit a shipped skill's doctrine from a single owned source.** Clean Code
  alone produced a confident, wrong conclusion; Beck's written content reversed it; the talk
  transcripts reversed it again. The final position matched none of the three intermediate readings.
  Mitigation: enumerate every relevant `.oracle/` source and consult ALL of them via the `oracle`
  agent BEFORE drafting.
- [ ] CONSTRAINT: **Never propose a grading-gate change without first running it against the negative
  controls.** Two proposals died here. `canary-compile` records `attributed_failures: 1` because its
  deliberate type error is runtime-inert, so any "if it produced an attributed failure, downgrade the
  type error" rule flips a control to pass. Mitigation: grade the compile canaries and read the fields
  before writing the rule.
- [ ] CONSTRAINT: **Gate on the PROCESS exit status, never on piped log text.** `node x.mjs | tail`
  reports `tail`'s status. A failing content checker read as GREEN once this session. Mitigation:
  redirect to a file, capture `$?` immediately, then inspect the file.
- [ ] CONSTRAINT: **Never reconstruct produced code from diff lines for a judge.** Two corpora were
  corrupted this way -- first `+`-only extraction (dropped the context lines the tests depend on),
  then hunk post-image stitching (joined disjoint regions into fabricated code). The damage was
  ARM-SKEWED 2:1 against the treated arms, i.e. biased against the thing being measured. Mitigation:
  `git show <recorded apply_base>:<path>` then `git apply` the real patch, and PARSE-GATE every
  specimen with the workspace TypeScript before any judge sees it, reporting the rate per arm.
- [ ] CONSTRAINT: **Judge/review subagents get READ-ONLY tools, or an explicit prohibition on writing
  to borrowed repos.** One judge copied 9 blinded specs into the borrowed `h3js/srvx` checkout to
  execute them. No tracked file was touched and it was cleaned, but the read-only invariant was broken
  by our own harness, not by a model under test.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
