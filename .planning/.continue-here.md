## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Fix breeds the same defect class | Three rounds, three self-falsifying claims, each arriving in the previous repair | blocking | Derive the claim from the table with a guard instead of asserting it in prose |
| Requirement lost in the authority document | The brief required it, CONTEXT.md omitted it, three gates validated against CONTEXT | blocking | Diff the authority against the original brief before dispatch |
| Verify block that passes on a no-op | Both of a plan's verify blocks exited 0 with nothing done | blocking | `&&`-chain, assert every leg, and RUN it against an unmodified tree |
| Needle outlives its subject | A guard keeps passing after the prose it protects is reworded, satisfied by a table cell or Sources bullet | blocking | Row-scope by a stable key and assert against a named column |
| Guard defeated by a delimiter | Deleting a cell's pipe makes the parser skip the row entirely; battery stays green and ~21 rows go invisible | blocking | Assert parsed row count against raw pipe-line count (ONE LINE, not yet applied) |
| Multi-word needle in a per-line scan | 6/6 caught single-line, 6/6 MISSED wrapped; "verified at the current wrap" is a snapshot, not an invariant | blocking | Flatten before matching, or use non-wrapping single-token stems |
| Relaying an unverified claim | Repeated a false `rg` gotcha from the global instructions; verified only when challenged | advisory | Run the controlled experiment before writing a fact into an instruction file |
